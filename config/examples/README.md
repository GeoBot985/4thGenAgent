# TaskFrame Example Configs

These files show the safe/default shape of TaskFrame configuration profiles.

- Copy one into `~/.taskframe/` or the directory selected by `TASKFRAME_CONFIG_DIR`.
- Keep real credentials, tokens, browser profiles, and local-only settings out of the repo.
- The files here use placeholders or safe defaults only.

Profiles:

- `taskframe.default.example.json`
- `taskframe.local-llm.example.json`
- `taskframe.google-live.example.json`
- `taskframe.rpa-local.example.json`
- `accounting_google_sheet.example.json`
